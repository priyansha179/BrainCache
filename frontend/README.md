# BrainCache Mobile Frontend

The planned client is **React Native + Expo**, following the mobile-first architecture in the project proposal.

The frontend has not been scaffolded yet. The next frontend milestone is to initialize an Expo TypeScript application, define navigation, and build the first screens for notes and tasks.

The mobile app will communicate with the FastAPI backend through a small API service module. Do not place API secrets or private credentials in the client application.
